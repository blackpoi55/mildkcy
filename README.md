# Private Paradise Resort เกาะช้าง — ระบบจัดการเช่ารถ & ซักผ้า

เว็บแอป Next.js สำหรับบันทึกข้อมูล 3 ส่วน โดยใช้ **Google Sheets เป็นฐานข้อมูล**

| ส่วน | หน้า | ใช้ทำอะไร |
|---|---|---|
| ทะเบียนรถ | `/bikes` | ข้อมูลรถ ทะเบียน ภาษี บัตร ชุดโอน เจ้าของ ราคาเช่า/วัน + แจ้งเตือนภาษีใกล้หมด |
| บันทึกเช่ารถ | `/rentals` | แตะรถเพื่อบันทึกว่าเช่าวันนี้ (รายวัน) / ตารางสัปดาห์แบบใน Excel / รายการทั้งเดือน พร้อมส่วนลด-ค่าปรับ |
| ซักผ้า | `/laundry` | เลือกห้อง (1–16 ไม่มี 13) + น้ำหนัก (ครึ่งกิโลได้) คิดราคาอัตโนมัติ สรุปรายห้อง/ค้างชำระ |
| แดชบอร์ด | `/` | รายได้รวม เช่ารถ ซักผ้า อัตราการใช้รถ ดูแบบ **รายวัน / รายสัปดาห์ / รายเดือน** กราฟ 12 เดือน รถทำเงินสูงสุด |
| ตั้งค่า | `/settings` | ตารางราคาซักผ้า รายการห้อง สถานะการเชื่อมต่อ นำเข้าข้อมูลจาก Excel |
| ติดตั้งแอป | `/install` | วิธีติดตั้งเป็นแอป (PWA) บน iPhone / Android / Windows / Mac + ปุ่มติดตั้งคลิกเดียว |

**สิทธิ์การเข้าถึง** (เมื่อตั้ง `APP_PASSWORD`): ไม่ล็อกอินดูได้เฉพาะ **แดชบอร์ด** (อ่านอย่างเดียว) และหน้าติดตั้งแอป
หน้าบันทึกเช่ารถ ซักผ้า ทะเบียนรถ และตั้งค่า ต้องล็อกอินก่อน

## ติดตั้งเป็นแอป (PWA)

ต้องเปิดผ่านลิงก์ **https://** (เช่น หลังเอาขึ้น Vercel) มือถือถึงจะติดตั้งได้ — รายละเอียดพร้อมรูปปุ่มอยู่ในหน้า `/install` ของแอป

| อุปกรณ์ | วิธีติดตั้ง |
|---|---|
| iPhone / iPad | Safari → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** → เพิ่ม |
| Android | Chrome → เมนู ⋮ → **ติดตั้งแอป** (หรือกดปุ่ม “ติดตั้งเลย” ในหน้า /install) |
| Windows | Chrome / Edge → ไอคอนติดตั้งในช่อง URL หรือปุ่ม “ติดตั้งเลย” |
| Mac | Safari → ไฟล์ → **เพิ่มไปที่ Dock** / Chrome → ไอคอนติดตั้งในช่อง URL |

ไอคอนแอปสร้างจาก `scripts/make-icons.mjs` (แก้สี/รูปแล้วรัน `node scripts/make-icons.mjs` ใหม่ได้)

## เริ่มใช้งาน (ในเครื่อง)

```bash
npm install
npm run dev
```

เปิด http://localhost:3000 — ถ้ายังไม่ได้ตั้งค่า Google Sheets ระบบจะทำงานใน **โหมดทดลอง** (เก็บข้อมูลในไฟล์ `.data/db.json`)

## เชื่อม Google Sheets (ทำครั้งเดียว ~10 นาที)

1. เข้า https://console.cloud.google.com → สร้างโปรเจกต์ใหม่
2. เมนู **APIs & Services → Library** → ค้นหา **Google Sheets API** → กด **Enable**
3. เมนู **APIs & Services → Credentials → Create credentials → Service account** ตั้งชื่ออะไรก็ได้ → Done
4. คลิก service account ที่สร้าง → แท็บ **Keys → Add key → Create new key → JSON** จะได้ไฟล์ .json มา
5. สร้าง Google Sheet ใหม่ (ว่างๆ) → กด **แชร์** → ใส่อีเมล service account (`xxx@xxx.iam.gserviceaccount.com`) สิทธิ์ **ผู้แก้ไข**
6. คัดลอก `.env.example` เป็น `.env.local` แล้วใส่ค่า
   - `GOOGLE_SHEET_ID` = ส่วนใน URL ของชีต `https://docs.google.com/spreadsheets/d/`**`ตรงนี้`**`/edit`
   - `GOOGLE_SERVICE_ACCOUNT_EMAIL` = `client_email` ในไฟล์ JSON
   - `GOOGLE_PRIVATE_KEY` = `private_key` ในไฟล์ JSON (ใส่ในเครื่องหมาย `"..."` คง `\n` ไว้)
   - `APP_PASSWORD` = รหัสผ่านเข้าเว็บ (แนะนำให้ตั้งเมื่อเอาขึ้นออนไลน์)
7. รีสตาร์ต `npm run dev` → ระบบจะสร้างแท็บ **รถ / เช่ารถ / ซักผ้า / ตั้งค่า** ในชีตให้อัตโนมัติ
8. ไปหน้า **ตั้งค่า → นำเข้า** เพื่อดึงรถ 19 คันและประวัติเช่า 1,286 รายการจาก Excel ต้นฉบับเข้า Google Sheet

> แก้ข้อมูลในชีตโดยตรงได้ แต่ **อย่าลบหรือแก้คอลัมน์ `id`** และอย่าเปลี่ยนชื่อหัวคอลัมน์

## นำเข้าข้อมูลจาก Excel

ไฟล์ `data/seed.json` สร้างจาก Excel ต้นฉบับด้วยสคริปต์ (ต้องมี Python + openpyxl):

```bash
python -I scripts/extract_seed.py "Motobike ต้นฉบับ.xlsx" data/seed.json
```

สคริปต์ตรวจยอดรวมให้ตรงกับที่ Excel คำนวณไว้ (413,850 บาท) ไฟล์นี้มีชื่อบุคคลจึงถูก `.gitignore` ไว้
การนำเข้าซ้ำจะข้ามรถ/วันที่ที่มีอยู่แล้ว

## เอาขึ้นออนไลน์ (Vercel)

1. push โค้ดขึ้น GitHub → import โปรเจกต์ใน https://vercel.com
2. ใส่ Environment Variables ทั้ง 4 ตัวเหมือนใน `.env.local`
3. นำเข้าข้อมูลจาก Excel ให้ทำจากเครื่องตัวเอง (ชี้ไปที่ชีตเดียวกัน) เพราะ `data/seed.json` ไม่ได้ขึ้นไปด้วย

```
src/app/actions.ts     Server Actions สำหรับบันทึก/แก้ไข/ลบ
src/app/(app)/...      หน้าต่างๆ
```
